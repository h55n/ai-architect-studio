# User Stories — AI Architect Studio

## Phase 1: Quiz

**US-01** — As a new user, I want to be greeted with a clean, distraction-free question screen so I can focus on describing my needs without UI overwhelm.

**US-02** — As a user answering the quiz, I want to see a progress bar filling as I answer so I understand how far along I am and feel a sense of momentum.

**US-03** — As a user, I want to type a free-text answer when expressing nuanced preferences so I'm not constrained to predefined options.

**US-04** — As a user, I want to tap option cards for multiple-choice questions so I can answer quickly without typing.

**US-05** — As a user, I want the AI to ask me a follow-up question that builds on my previous answer so the conversation feels intelligent and personal.

**US-06** — As a user, I want the quiz to end after 5–8 questions — not 20 — so I feel respected and don't experience survey fatigue.

## Phase 2: Cinematic

**US-07** — As a user who just finished the quiz, I want to see an engaging animation while my design is being generated so the wait feels exciting rather than frustrating.

**US-08** — As a user watching the cinematic, I want to see my actual design specs (room count, style, area) typed out in front of me so I feel the AI truly understood me.

**US-09** — As a user in a hurry, I want a skip button on the cinematic so I can jump straight to the 3D viewer when I'm ready.

## Phase 3: 3D Viewer

**US-10** — As a user, I want to orbit around my 3D house with smooth, damped mouse/touch controls so I can inspect it from any angle naturally.

**US-11** — As a user, I want to explode the floors apart so I can understand how each level is arranged without the walls blocking my view.

**US-12** — As a user, I want to drag a cutaway slider to reveal the interior at different heights so I can see inside any floor as if the ceiling were transparent.

**US-13** — As a user, I want to cycle through concrete, timber, and brick material presets so I can explore how different finishes change the feel of my home.

**US-14** — As a user, I want to switch to a 2D top-down floor plan view so I can understand the spatial layout from an architectural perspective.

**US-15** — As a user, I want to hover over a room and type "add a king bed" or "add a home office desk" and see the furniture appear immediately so I can rapidly customize my space.

**US-16** — As a user, I want the room I'm hovering to show its name (e.g., "Master Bedroom") so I can navigate the house without losing orientation.

**US-17** — As a developer/power user, I want the 3D viewer to maintain 60fps so the experience feels premium and responsive.

## Cross-Cutting

**US-18** — As a user on any device, I want the quiz to work perfectly on my phone so I can complete the intake anywhere.

**US-19** — As a user who prefers dark environments, I want a dark mode so the application adapts to my preference or system setting.

**US-20** — As a user, I want clear error messages if something goes wrong with the AI so I understand the problem and know what to do next.
